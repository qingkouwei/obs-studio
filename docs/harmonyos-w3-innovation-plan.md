# OBS 鸿蒙版 · W3 创新项规划（基于 HarmonyOS 7 / API 26 新特性）

> 基线：HarmonyOS 7.0.0 / API 26 / 验证机 MatePad Edge（QXS-W00，Pad/PC 双形态）。
> 所有可行性均经官方文档逐条核实（开发者知识库检索 2026-10-03），出处随文。
> 定位原则：不做"移植补票"，做**只有鸿蒙版才能做**的功能——这些是文章系列
> "前沿探索篇"的素材池，也是 QingStudio 产品差异化的卖点池。

## 一、能力核实矩阵（先看硬约束）

| 能力 | 文档约束 | 对我们验证机的适用性 |
|---|---|---|
| 碰一碰分享（Share Kit harmonyShare） | 手机↔手机、**手机↔PC/2in1** 均有官方指导与最佳实践；PC 端监听需传 windowId；亮屏解锁+华为分享开启 | ✅ 直接可用；API 26 起还有 serviceinteraction 通用碰一碰数据交互（顶端触碰连接+数据交换，不限分享语义） |
| 隔空传送（一抓一放手势） | 开关=设置>系统>快捷启动和手势；接收端电脑→文件入文件管理器 | ⚠️ 需真机确认本机手势支持（文档以手机/平板发起为主，PC 为接收端） |
| 实况窗 Live View Kit | **"当前仅支持 Phone 和 Tablet 机型"**（官方范围原文）；权益申请需**已上架应用+月活≥1000**；单实况≤8h；本地创建 API 26 图片限 192KB | ⚠️ 双卡点：①机型口径——我们的平板形态在"Tablet"内，PC 模式是否算需实测；②**权益需上架后申请**→排期必须放上架之后 |
| 跨设备互通相机（ServiceCollaboration Kit） | 本端=**PC/2in1 或 Tablet**，远端=有相机的 Phone/Tablet；同华为账号+WLAN/蓝牙；**API 6.1.0(23) 起正式支持 PC/2in1 本端**；调用策略 PC→平板/手机 | ✅ 完美匹配：这就是官方背书的"手机当 PC 摄像头"，正是 OBS 要的无线摄像头源 |
| 意图框架 Intents Kit（小艺入口） | 一步达 JumpFunctionPage（API 18+）；垂域意图注册 insight_intent.json；**官方明示"意图框架兼容 MCP"**；支持后台执行模式 onExecuteInUIAbilityBackgroundMode | ✅ 可用；直播类无专属垂域→用一步达+自定义入口意图组合 |
| 跨设备协同连接（AbilityConnectManager，API 18+） | 组网内跨设备拉起 Ability + 双向实时数据传输；同账号自组网或发现绑定 | ✅ 可做导播台/遥控器的信令+数据通道 |
| 分布式数据对象/键鼠共享/跨设备剪贴板拖拽 | 系统能力，拖拽需组件实现 drag/drop 即可接入 | ✅ 低成本彩蛋：素材跨设备拖进 OBS 场景列表 |
| 接续（onContinue） | UIAbility 标准迁移钩子 | ✅ OBS 窗口布局/场景配置随应用流转到另一台设备 |
| HarmonyOS 7 新特性 API 26 增量 | serviceinteraction 碰一碰（26.0.0 起）；实况窗 lifeCycleMode=AUTO_STOP_WHEN_APP_TERMINATE（26.0.0 起，**进程退出自动关实况**——录制崩溃不留僵尸胶囊，正合适）；网络报文分析（26.0.0，调试推流抓包神器，开发期工具非产品功能）；Vulkan 支持 OHNativeWindow/OH_NativeBuffer 创建 Surface | ✅ 前两项直接服务于我们的场景 |

## 二、创新项菜单（按"价值×可行性×素材力"排序）

### S 档：主推（本迭代做）

**C1. 碰一碰开播（手机→OBS 无线摄像头源）**
手机碰 PC/2in1 上的 OBS → OBS 拉起跨设备互通相机/分布式通道 → 手机摄像头实时入画开播。
- 组合：harmonyShare.on('knockShare')+dataReceive（触发信令）+ ServiceCollaboration 远程相机（视频流）或 AbilityConnectManager 自建拉流通道（若互通相机帧规格不够，退到软总线双端 OBS 传 H.264 裸流）。
- 一句话演示效果极强的发布会功能；官方两条能力线全部 ≥23/26 支持我们形态。
- 风险：远程相机回传分辨率/帧率规格需实测；非同账号场景需降级。
- 素材力：★★★★★（"手机一碰，电脑开播"）

**C2. 碰一碰分享成片 / 推流链接**
录制完成页/直播页：与另一台设备碰一下 → 成片（MPEG4 文件）或推流/回放链接（HYPERLINK）直接飞过去。官方最佳实践现成（bpta-application-knock-file-share / video-share / pc-phones-mutually 全套代码）。
- 成本极低（harmonyShare 一个监听+share() 调用），价值直观：录完碰给同事/发群。
- 建议做成 C1 的第一级台阶（同一监听体系，先上文件分享再上开播信令）。
- 素材力：★★★★

**C3. 小艺一句话开播/录制**
insight_intent.json 注册（JumpFunctionPage 一步达 + 自定义"开始直播/开始录制"入口意图，支持后台执行模式）→"嘿小艺，用 OBS 开始直播"→ 应用后台拉起、按持久化配置直接开播。
- 与已有"设置持久化+长时任务"天然闭环；官方"意图框架兼容 MCP"一句还给我们留了 Agent 生态叙事（AI PC 卖点，与 WorkBuddy/MCP 语境接得上）。
- 风险：入口意图在小艺对话的实际命中率需真机+真账号验证；无直播垂域，用通用意图+一步达组合是合规路径。
- 素材力：★★★★（"AI PC 的语音开播，比 OBS 桌面版的硬件快捷键更性感的入口"）

### A 档：紧接其后

**C4. 手机导播台（分布式遥控器）**
手机与 PC 登同账号组网 → 手机侧轻量遥控器页（场景切换/起停录制/推流状态监视），信令走 AbilityConnectManager 或分布式数据对象（场景状态天然同步）。
- 官方能力 18+ 稳定；需要两台设备做验证（当前只有一台——排期卡点，可向用户借手机真机）。
- 素材力：★★★★

**C5. 实况窗直播状态（上架后的锦上添花）**
直播进行中：状态栏胶囊（REC/LIVE+时长）+锁屏实况，用 API 26 新 lifeCycleMode AUTO_STOP_WHEN_APP_TERMINATE 保证进程异常不留僵尸胶囊。
- **硬卡点：权益申请要求"已上架+月活≥1000"** → 此功能开发可先做（本地实况在开发环境可调试展示效果），正式开通必须放上架后。机型"仅 Phone/Tablet"在 PC 模式下的支持面需实测记录。
- 素材力：★★★

**C6. 应用接续 + 跨设备拖素材（彩蛋级，成本超低）**
- onContinue：OBS 运行态（场景/来源/设置）搬到另一台设备无缝续作；
- 跨设备拖拽/系统剪贴板：手机相册照片长按拖过屏幕边框直接进 OBS 场景列表（实现 drop 接收即可，官方称"系统自动处理跨设备传输，开发者无需介入"）。
- 素材力：★★★（每个都是好截图好视频）

### B 档：长线

**C7. ArkWeb 浏览器源**：对应桌面 CEF 浏览器源的鸿蒙替代（❌-B 表既定项），推流叠加网页/弹幕面板；独立插件工程，量大，单独排期。
**C8. HDR Vivid 录制**：HEVC Main10 路径官方文档证实存在（HDR Vivid 指导就是 CreateByMime(HEVC) 起步）；需色彩管线 HDR 化+机型能力探测，量最大。
**C9. 隔空传送收素材**：一抓一放把手机素材扔进 OBS——依赖本机手势支持确认（见矩阵 ⚠️）。

## 三、建议实施节奏

1. **本批（今晚可做，单设备）**：C2 碰一碰成片/链接分享（需第二台设备验收——代码+自测监听注册先行）+ C3 意图注册（本机可验证小艺调用）+ C6 接续/拖拽骨架。
   - **进度（10-03 晨）**：C2 双向代码闭环——接收侧 `KnockShareReceiver`（手机图库图片碰进来→建图片源）、发起侧 `KnockShareSender`（停止录制后碰一下把成片 mp4 发出去）。C3 意图注册闭环——`insight_intent.json` 声明 StartLive/StartRecording（MediaDomain/前台/绑 EntryAbility），`OBSIntentExecutor` + `IntentActions` 待处理队列解决"冷启动执行器早于 initialize"时序。三者均编译进包验证（modules.abc + HAP profile）；设备侧运行时冒烟（监听恰好注册一次、意图被小艺命中）待设备回线；端到端碰一碰需第二台鸿蒙设备（用户手机）。C6 接续 onContinue 签名已核实（`onContinue(wantParam, since 11): OnContinueResult|Promise`），骨架待写。
2. **下批**：C1 碰一碰开播（先跑互通相机分辨率实测）→ 成功后 C2/C1 合并成"碰系列"叙事。
3. **上架后**：C5 实况窗权益申请（申请文案可复用 AGC 材料套路）+ C4 双机联调完整版。
4. **长线**：C7 → C8。
